# Sistem Informasi SDN Doplang

Proyek ini adalah Sistem Informasi untuk SDN Doplang, dibangun menggunakan Laravel.
Proyek ini dibuat untuk keperluan Kerja Praktek dan akan digabungkan dengan modul PPDB.

## Instalasi
1. Clone repository
2. Jalankan `composer install`
3. Salin `.env.example` ke `.env` dan konfigurasikan database.
4. Jalankan `php artisan key:generate`
5. Jalankan `php artisan migrate:fresh --seed`
6. Jalankan `php artisan serve`
